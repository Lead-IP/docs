<Update label="October 22, 2026" description="Email enrichment and prospector reveal" tags={["API"]}>
  ## Email enrichment works again

  [Enrich Email](/api-reference/email/enrich) finds a work email from a name and company domain, or from a prospector `document_id`. It is billed only when it returns a new verified email. Other outcomes are refunded.

  ## Prospector reveal

  - [Reveal](/api-reference/prospector/reveal) and [bulk reveal](/api-reference/prospector/reveal-bulk) are now billed in the same way and need the `prospects:write` scope.
  - They return fewer fields. Phone and name fields are gone, and the response carries the email, its verification state and the billing outcome.

  ## Enrich contact and enrich company

  `POST /v1/enrich/contact` and `POST /v1/enrich/company` are back. They run on verified data providers and send results to review instead of writing them directly.

  ## Rate limit

  The API rate limit is 500 calls a day per key.
</Update>

<Update label="October 21, 2026" description="MCP documentation" tags={["MCP", "Docs"]}>
  ## LeadLex MCP server docs

  The LeadLex MCP server now has its own section in these docs.

  - Connect [Claude](/mcp-server/connect-claude), [ChatGPT](/mcp-server/connect-chatgpt), [Cursor](/mcp-server/connect-cursor) or [any other client](/mcp-server/connect-other) to `https://mcp.leadlex.com/mcp`.
  - Sign in with OAuth 2.1 or a workspace API key. See [Authentication](/mcp-server/authentication).
  - Browse all 99 [tools](/mcp-server/tools), the [resources and prompts](/mcp-server/resources-and-prompts) and [example requests](/mcp-server/examples).
  - Read how workspace isolation and sending safeguards work on the [Security](/mcp-server/security) page.

  ## API reference

  - The OpenAPI spec is now published with the docs at `api-reference/openapi.yaml`.
  - The docs use LeadLex branding.
  - Two endpoints that were missing from the reference are now generated from the spec: `GET /v1/campaigns/{id}/steps/{stepId}` and `GET /v1/companies/{id}/documents`.
</Update>
