The LeadLex MCP server lets an AI assistant work inside your LeadLex workspace. You ask in plain language. The assistant searches your contacts, creates a deal, books a follow-up task or drafts a campaign, and it does so with your own CRM data.

MCP (Model Context Protocol) is the open standard that AI assistants use to talk to outside tools. LeadLex runs a remote MCP server, so there is nothing to install.

## Endpoint

```
https://mcp.leadlex.com/mcp
```

The server speaks streamable HTTP. You can sign in with OAuth 2.1 or with a workspace API key. See [Authentication](/mcp-server/authentication).

## How it relates to the REST API

The MCP server and the [REST API](/api-reference/contacts/list) work on the same workspace data. Use MCP when an AI assistant is the user. Use the REST API when your own code is the client.

## Workspace isolation

Every call runs inside the workspace of the account that signed in. You never pass a workspace or company id, and the tools do not accept one. Read more on the [Security](/mcp-server/security) page.
