The LeadLex MCP server exposes **99 tools**. Your AI assistant picks the right one from your request, so you rarely name a tool yourself. This page is the reference for what exists.

<Note>
Tools marked **OAuth only** act on behalf of a signed-in user and refuse a workspace API key. Connect with OAuth to use them. See [Authentication](/mcp-server/authentication).
</Note>
