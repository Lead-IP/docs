title: "Connect ChatGPT"
description: "Add LeadLex to ChatGPT as a custom MCP connector."
---

ChatGPT connects to LeadLex as a custom connector that points at the remote MCP server.

<Steps>
  <Step title="Open connector settings">
    In ChatGPT, open **Settings** and go to **Connectors**. Custom MCP connectors may need developer mode to be switched on. [NEEDS: confirm current ChatGPT menu names and which plans can add custom MCP connectors]
  </Step>
  <Step title="Create the connector">
    Add a new connector. Use `LeadLex` as the name and this URL as the MCP server URL:

    ```
    https://mcp.leadlex.com/mcp
    ```
  </Step>
  <Step title="Choose OAuth">
    Select OAuth as the authentication method. LeadLex supports dynamic client registration, so ChatGPT does not need a pre-created client id.
  </Step>
  <Step title="Approve access">
    Sign in to LeadLex and approve the consent screen.
  </Step>
</Steps>

In a new chat, enable the LeadLex connector and ask something like "Show me my open deals".

<Tip>
  OAuth is the right choice for ChatGPT. Tools that act on your own LinkedIn account or mailbox need a signed-in user and do not work with an API key.
</Tip>
